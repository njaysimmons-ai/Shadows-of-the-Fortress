# Living NPCs: the living world
#
# What sims and NPCs DO: actions, reactions, group banter, memories and emotes.
# Press Ctrl+F8 in game to reload.
#
# Sections can be specialised. The mod tries, in order:
#   [section.<persona>]     e.g. [react.death.grump]       (personas are listed in sims.txt)
#   [section.mood.<mood>]   e.g. [react.death.mood.low]    (moods: low, high)
#   [section]
# Some also have relationship versions: [react.death.friend], [react.death.rival].
#
# Action lines are written as what the sim does, and appear as an emote:  "Bob stretches."
# Start an action with an animation tag to play it:  [dance] [sit] [flourish] [kneel]
#
# Tokens: {player} you  {other} another sim  {zone} current zone  {count} a number
#         {wipezone} where you last wiped together  {lastzone} where you last fought together
