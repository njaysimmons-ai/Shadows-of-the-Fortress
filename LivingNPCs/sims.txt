# Living NPCs: sim player personas
#
# Erenshor builds every generated sim from the same template, so they all sound alike. Each one
# now gets a persona, picked from its name, so it keeps the same persona every time you play.
# A persona changes how the sim types and mixes its own lines into the game's.
# Hand-made sims keep their own voices unless you turn on AlsoChangeHandmadeSims in the config.
# Press Ctrl+F8 in game to reload; sims pick up changes the next time they spawn.
#
# [persona.<id>] settings, one per line:
#   @weight=10        how common this persona is
#   @fits=1,2,3,5     only for sims with these game temperaments: 1 nice, 2 tryhard, 3 mean, 5 plain
#   @lower=0.8        chance a sim with this persona types all in lowercase
#   @caps=0.2         chance it types IN ALL CAPS
#   @emojis=0.3       chance it sprinkles emojis
#   @thirdperson=0.1  chance it talks about itself in the third person
#   @typos=0.2-0.6    how sloppy its typing is (a range; each sim lands somewhere in it)
#   @signoff=lol|ya   occasional tag at the end of a message; each sim gets one of these
#
# [persona.<id>.<List>] lines added to one of the game's phrase lists for that persona:
#   GenericLines         small talk shouted in zone chat (a ? makes other sims answer)
#   Greetings            one or two words: "hey", "yo". The game adds the "!" or the next words
#   Invites              asking you to group. NN is your character's name
#   Justifications       the reason after an invite: "we need a healer"
#   Confirms, Affirms    yes / sure / omw
#   DeclineGroup         turning down a group invite
#   OTW                  "on my way"
#   Died                 said to the group after dying
#   Exclamations         a word or two: "ugh". Also used before an insult
#   InsultsFun           friendly trash talk aimed at another sim
#   RetortsFun           replies to trash talk
#   Impressed            reacting to a good drop or kill
#   Gratitude            thanks for a buff or item
#   AcknowledgeGratitude "np"
#   LevelUpCelebration   shouted on leveling up
#   Goodnight            logging off
#   WantsDrop            asking for loot. II is the item's name
#   GoodLastOuting, BadLastOuting, BeenAWhile   remembering the last time you grouped
#
# [smalltalk.zone.<Zone>] small talk any persona can use in that zone (scene name, see the log).
# [sim.<Name>] with @persona=<id> forces one sim to a persona.
